# Custom UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar `vba ui` seguro para editar Ribbon Custom UI de `.xlsm` y evitar ejecución concurrente con `vba dev`.

**Architecture:** `VbaDev.psm1` conserva lógica ZIP, XML y lock de sesión. `vba.ps1` expone comando `ui`. `dev` adquiere mismo lock antes de abrir Excel; `ui` modifica solo libro cerrado.

**Tech Stack:** Windows PowerShell 5.1, .NET `System.IO.Compression`, XML .NET, Excel COM existente.
